# Poly-Bot- (DILA),(DIMO)

A full-stack web application built using the MERN stack.

## 🚀 Overview

Poly-Bot is a web-based application designed to demonstrate the practical integration of a scalable backend database with a dynamic frontend interface. It handles data processing, API routing, and state management across the application.

## 💻 Tech Stack

* **Database:** MongoDB
* **Backend:** Node.js, Express.js
* **Frontend:** React.js

## ⚙️ Local Setup Instructions

### Prerequisites

* MongoDB database access (Local or MongoDB Atlas)
